# 云端部署说明

公网临时预览地址为 http://106.14.75.30:9000/，由独立 `qingchang-preview` 容器仅提供网页静态文件，不代理 `/ai`，也不携带评分令牌。此地址使用 HTTP，适合浏览和本地导入文件；浏览器录音需要安全上下文，应通过下文的 SSH 本机入口使用。HTTPS 域名尚在申请中。

轻唱原有网页和轻量网关仍部署在 aliyun 的 `/opt/qingchang-web`，只监听 127.0.0.1:8765，通过 SSH 本机入口访问。citygis-cloud 的 `qingchang-tunnel.service` 使用专用密钥保留反向隧道，将 aliyun 的 127.0.0.1:8878 转发至 citygis 的 127.0.0.1:28787。网关令牌不得纳入版本库或浏览器资源。网页构建使用 `VITE_AI_ENDPOINT=/ai npm run build`。

MiniCPM 评分方案已取消，原 worker 下载与部署已停止。新的实时 CREPE + DTW 和录后 VocalVerse 已部署；实际浏览器体验和评分效果以验收结果为准。citygis 的既有推理服务继续运行，不属于本次预览服务。

预览容器复用现有 `qingchang-web:local` 镜像，覆盖启动命令为 Python 静态文件服务，仅提供 `/opt/qingchang-app/dist`，绑定 0.0.0.0:9000，限制 0.25 CPU 和 128 MiB，禁用继承的健康检查。不挂载网关环境文件，也不设置评分令牌。容器不应被当作 HTTPS 或评分服务。

本次 aliyun 的官方 Python 镜像源返回 not found，因此本机构建固定使用现有基础镜像 ID `sha256:7aba4cc0cbc9a354bc4d6fd1bbf090db3d7acac6188c24e17ea3e74a4ddb489c`，以独立虚拟环境从阿里云 PyPI 镜像安装依赖，覆盖工作目录、启动命令和健康检查。生成的 `qingchang-web:local` 是该主机的本地镜像，不是可移植的官方基础镜像；未推送。容器仅使用 host 网络，限制 0.5 CPU、256 MiB，不挂载业务目录。远端实际构建文件为 `/opt/qingchang-web/Dockerfile.local`，令牌文件和环境文件不进入构建上下文。

在具备 `ssh aliyun` 免密连接的本机执行 `scripts/云端访问.sh`，然后访问 http://127.0.0.1:8765。脚本会记录专用 SSH 进程 PID 到 `.tools/deployment/web-tunnel.pid`；结束访问时先用 `ps -p "$(cat .tools/deployment/web-tunnel.pid)" -o command=` 核对进程是本项目的 SSH 转发，再用 `kill "$(cat .tools/deployment/web-tunnel.pid)"`。如果 8765 已占用，SSH 会报错，不替换现有监听进程。

检查隧道可执行 `ssh citygis-cloud systemctl status qingchang-tunnel`；本机直连路径不稳定时，可使用已验证的 `ssh -J aliyun citygis-cloud` 跳板连接，不必修改 SSH 配置。检查网页容器可执行 `ssh aliyun docker ps --filter name=qingchang-web`。隧道专用密钥和已验证的主机公钥位于 citygis-cloud `/opt/qingchang-tunnel`，授权条目标记为 `qingchang-tunnel`。密钥仅允许反向监听 127.0.0.1:8878，远程命令被禁止；OpenSSH 的 `permitopen` 将本地转发限定为当前未监听的 127.0.0.1:1。

仅撤销公网预览时，执行 `ssh aliyun docker rm -f qingchang-preview`。撤销完整部署时，先删除该预览容器，再停止本机隧道进程，删除 aliyun 的 `qingchang-web` 容器及 `/opt/qingchang-web`，停止并禁用 citygis-cloud 的 `qingchang-tunnel.service`、移除其服务文件和 `/opt/qingchang-tunnel`，并仅删除 aliyun `authorized_keys` 中标记 `qingchang-tunnel` 的条目。评分 worker 的撤销另按其部署说明操作；不要修改其他服务或授权条目。
