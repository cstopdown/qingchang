# 练唱评分方案

录制期间使用官方 CREPE 估计人声基频，并与曲目绑定的参考旋律在线 DTW 对齐。展示平均音准误差、±50 cent 命中率、节奏偏移和覆盖率；这些指标分别呈现，不合成为总分。无参考时仅展示音高。可导入参考人声提取旋律，或导入 version 1 音高 JSON（包含 title、offsetSeconds、hopSeconds 0.05 和 frames）。已有三首示例只有伴奏，不提供参考旋律。参考设置及实时汇总保存在本机；作品保留录制时的参考信息。

录音完成后，VocalVerse2 MuQ KTV v2 使用保存的干声给出模型原生 0–100 实验分数，并标明实际分析片段；没有干声的旧作品不能进行新评分。旧版报告作为历史记录保留。实时指标和录后模型分数是不同结果。

**当前录后模型不能用来判断唱功或录音质量。** 同一段清唱在原音、中度退化、重度退化下分别得到 66.80、70.24、82.10，出现加噪和失真反而抬高分数的反例。因此界面明确标为模型实验分数，保留原始值，不反转、不伪造校准，也不生成不存在的四维点评。具体模型、片段处理、来源和真实对照见 [CPU 服务部署与验收](../vocal_service/部署与验收.md)。

公共 HTTP 9000 入口提供静态页面，不代理评分，浏览器也不能在非安全上下文使用麦克风。私人录音入口为配置 SSH 隧道后的 http://127.0.0.1:8765；评分连接是否可用以设置中的真实健康检测为准。服务端令牌由网关持有，不发送到浏览器。CPU worker 已部署，并完成真实模型和浏览器评分验证；本轮结果见 [网页评分验收](./网页评分验收.md)。

浏览器第一次加载 CREPE 需要时间，模型状态会显示加载中。加载失败或在短录结束时尚未完成分析，评分会明确报错，原始录音仍可保存。没有参考旋律的歌曲只显示音高；可以先添加自制 C 大调音阶直接体验完整流程。既有伴奏不自动作为参考人声使用。
