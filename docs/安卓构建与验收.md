## 本机项目内工具链

所有工具和下载缓存放在被 Git 忽略的 `.tools/`，未改系统 Java、系统 Android SDK 或 shell 启动配置。

| 工具 | 实际版本与路径 |
| --- | --- |
| JDK | Amazon Corretto `21.0.13`，`.tools/java/amazon-corretto-21.jdk/Contents/Home` |
| Android SDK | `.tools/android-sdk`，已安装平台 `android-36` |
| Build Tools | `35.0.0` 由 AGP 按需安装；预先准备的 `36.0.0` 也保留在项目 SDK 中 |
| Platform Tools | AGP 按需安装 `37.0.1` |
| Gradle | 工程 wrapper 固定 `8.14.3`，缓存 `.tools/gradle-user-home` |
| Android 用户缓存 | `.tools/android-user-home`，含本轮开发用 `debug.keystore` |

在这台机器的项目根目录执行：

```sh
JAVA_HOME="$PWD/.tools/java/amazon-corretto-21.jdk/Contents/Home" \
GRADLE_USER_HOME="$PWD/.tools/gradle-user-home" \
ANDROID_USER_HOME="$PWD/.tools/android-user-home" \
ANDROID_HOME="$PWD/.tools/android-sdk" \
ANDROID_SDK_ROOT="$PWD/.tools/android-sdk" \
npm run android:build
```

命令会重新构建共享 Web 资源、同步 Capacitor 插件与静态资源，再运行 Android `assembleDebug`。首次构建需要联网下载 Java 构建依赖；本机缓存不纳入 Git，其他机器不能假定已存在这些目录。

工具来源与校验：JDK 来自 [Amazon Corretto 官方下载](https://docs.aws.amazon.com/corretto/latest/corretto-21-ug/downloads-list.html)，下载包 SHA256 为 `f4ee9236ffc3ddcd37da877e04a1ab74b3d3376cf9e4287b5426f4749cc869a9`；Android 命令行工具和 SDK 来自 [Android 官方工具下载](https://developer.android.com/studio#command-tools)。Gradle 官方分发跳转 GitHub 后速度过慢，因此使用华为镜像传输同版本包，执行前与 [Gradle 官方 SHA256](https://services.gradle.org/distributions/gradle-8.14.3-all.zip.sha256) `ed1a8d686605fd7c23bdf62c7fc7add1c5b23b2bbc3721e661934ef4a4911d7c` 核验一致后才填入项目 wrapper 缓存。

本轮还遇到 Maven Central 的一个 Kotlin JAR 被 Java TLS 连接中断；从同一官方地址用 `curl` 取回并核验官方 SHA1 后补入缓存，随后在线解析元数据并完成构建。没有降低 TLS 校验或修改工程仓库。

## 常规开发与正式发布环境

常规 Android 开发环境可使用独立 JDK 21 和 Android Studio 提供的 SDK，安装工程声明的 SDK 平台 36，并由构建插件安装其所需的 Build Tools。配置有效的 `JAVA_HOME` 和 `ANDROID_HOME`，按工具提示接受 SDK 使用条款，然后执行：

```sh
npm ci
npm run android:build
```

日常只同步资源时运行 `npm run android:sync`；也可在 Android Studio 打开 `android/` 工程。完整流程仍需在目标设备上核验麦克风权限、导入音频、耳机返听、录音保存、系统分享及离线重启后的曲库保留。

正式发布需要自行配置并保护 Android 签名密钥，不能复用本轮 debug 密钥。当前记录不包含商店发布、正式签名或目标设备安装结果。
