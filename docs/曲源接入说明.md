# 曲源接入说明

## 结论与当前行为

铜钟音乐与煎饼搜都没有查到公开伴奏库或官方开放 API 的证据。本期将它们作为外部站点入口，用户自行取得有权使用的文件后，从本地导入轻唱。普通歌曲、带原唱音频和纯伴奏应由用户自行区分；导入不会自动消除原唱。

本期没有后台爬虫、页面解析服务、下载代理、站点口令自动处理或付费内容解锁。应用内的曲库搜索仅搜索本地数据，不表示支持搜索这两个站点。

## 接入规则

站点入口固定打开 `https://tonzhon.com/` 与 `https://www.jbsou.cn/`，不构造未经验证的搜索参数。站点返回口令、403、登录或验证码时，由用户在外部浏览器处理，轻唱不代为绕过。

音频直链导入是独立功能，只接收 HTTP(S) 音频文件地址。浏览器按来源站点的 CORS 策略读取，不发送跨站凭证，不通过额外后端代理绕过限制；内容过大、网络失败、跨域拒绝或不能解码时不入库。无法直链导入时，用户可使用有权取得的本地文件。

如果未来站点提供正式 API，应先确认文档、权限、资源类型和使用限制，再扩展源适配器；当前不声明存在任何这类接口。
