# 苹果手机自用安装

轻唱的 iOS 版本面向自己的 iPhone。共享界面与音频业务通过 Capacitor 放进 WKWebView，不需要为个人使用建设社区或提交 App Store。当前已生成并同步 iOS 工程，尚未编译、签名或在 iPhone 运行。

## 准备条件

截至 2026-10-30，[Capacitor 官方 iOS 文档](https://capacitorjs.com/docs/ios)要求 Xcode 26.0 或更新版本，支持 iOS 15 及更新系统。需要一台兼容该 Xcode 的 Mac、自己的 iPhone，以及用于在 Xcode 登录的 Apple 账号。当前开发机器只有 Command Line Tools，没有完整 Xcode；工程同步成功不能证明已经生成 iPhone 应用。

[Apple 官方账号说明](https://developer.apple.com/help/account/basics/about-your-developer-account)支持在 Xcode 登录免费账号，使用 Personal Team 将应用安装到个人设备。免费配置文件自签发起 7 天过期，到期后需要重新构建并安装。Apple 同时限制免费 Team 的 App ID、设备和每台设备安装数量，实际额度以该官方页面与 Xcode 提示为准。

## 安装步骤

1. 在 Mac 安装并打开完整 Xcode，完成它提示的必要组件准备；在 Xcode 的账号设置中登录自己的 Apple 账号。账号只需要在自己的 Xcode 中使用。
2. 在项目目录安装依赖并同步资源：

   ```sh
   npm ci
   npm run ios:sync
   npm run ios:open
   ```

3. 在 Xcode 选择应用 Target 的 Signing & Capabilities，启用自动签名，并选择自己的 Personal Team。若应用标识与现有标识冲突，设置为自己唯一的 Bundle Identifier。
4. 连接并解锁自己的 iPhone，按设备与 Xcode 提示完成信任及开发准备，选择该设备作为运行目标，然后点击运行。
5. 首次录音允许麦克风访问。戴有线耳机，先测试麦克风和耳机返听，再录制短片段，核对音量、音色、延迟与作品导出。

## 后续维护

修改共享界面、音频代码或演示素材后，重新运行 `npm run ios:sync`，再从 Xcode 安装。免费 Personal Team 的 7 天配置文件到期后，也需要重新构建安装；它不适合期待长期免维护的分发。

曲库与作品保存在当前应用环境中，重要作品请导出留存。iPhone 上的麦克风、音频路由、耳机返听延迟、系统分享与存储保留都需要真机验证，当前记录见[验收记录](./验收记录.md)。
