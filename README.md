# 轻唱 Qingchang

轻唱是一个面向个人练唱的应用。导入自己的伴奏与歌词，在设备上录音、混音、回放和导出作品。基础练唱无需账号或评分服务；浏览器、桌面和移动端共用一套界面与音频逻辑。

## 主要功能

- 导入本地音频或可跨域访问的 HTTP(S) 音频直链，附加 LRC 或纯文本歌词；提供原创演示曲目。
- 管理本地曲库、收藏和作品；录制时可调整返听、音色、音量、混响与延迟补偿，作品可回放和导出。
- 使用浏览器内的 CREPE 检测人声音高；绑定参考人声或音高数据后，通过 DTW 显示音准、节奏和覆盖率等实时指标。
- 可选连接私有 VocalVerse 服务，对已保存的人声干声进行录后评估。模型输出为实验分数，当前不能用来判断唱功或录音质量。

曲库与作品保存在当前浏览器或应用的 IndexedDB 中，不会自动跨设备同步。清除站点或应用数据、卸载应用可能删除内容，请及时导出重要作品。第三方音频需有使用权限，歌曲网页地址不一定是可导入的音频直链。

## 本地运行

需要 Node.js 24 或更新版本及 npm。在项目目录运行：

```sh
npm ci
npm run dev
```

打开 `http://127.0.0.1:5173/`。选择演示曲目或导入伴奏，佩戴耳机并允许麦克风权限后，即可测试和录音。浏览器录音需要安全上下文；本机回环地址可用于开发，远程访问需要 HTTPS。

```sh
npm test             # 功能测试
npm run test:e2e     # 浏览器验收，需要 Google Chrome
npm run build        # TypeScript 检查和生产构建
npm run preview      # 预览构建结果，默认 127.0.0.1:4173
```

## 实时对比与录后评估

实时 CREPE 模型和 WASM 资源随网页提供，分析在本机运行。没有参考旋律时只显示音高；可添加参考人声、音高 JSON 或使用内置音阶练习体验对比。示例伴奏本身不自动作为参考旋律。

录后评估需要单独配置可访问的私有 VocalVerse 服务，在应用设置中保存地址并检测连接。模型权重和服务运行环境不包含在普通网页构建或安装包中，连接是否就绪以健康检测为准。历史作品如果没有保存干声，不能进行新的录后评估。部署和模型限制参见[评分方案](./docs/评分方案.md)与[服务部署与验收](./vocal_service/部署与验收.md)。

## 桌面与移动端

| 平台 | 命令 | 说明 |
| --- | --- | --- |
| 桌面 | `npm run desktop:dev`、`npm run desktop:pack`、`npm run desktop:dist` | Electron；分别用于开发、生成当前系统应用目录和安装包。 |
| Android | `npm run android:sync`、`npm run android:build` | Capacitor；构建需要 JDK 21 和 Android SDK，生成 debug APK。 |
| iOS | `npm run ios:check`、`npm run ios:sync`、`npm run ios:build`、`npm run ios:run`、`npm run ios:open` | 需要完整 Xcode 26+；应用最低 iOS 16.4，真机自用需签名和设备开发者模式。 |

构建结果和设备体验需分别验收。已有平台验收记录属于对应版本的历史结果，Windows 与手机录音、系统导出及权限交互仍需在目标设备验证。详情见[跨平台方案](./docs/跨平台方案.md)、[安卓构建与验收](./docs/安卓构建与验收.md)和[苹果手机自用安装](./docs/苹果手机自用安装.md)。

## 项目结构

- `src/`：界面、音频处理、曲库、实时对比与平台适配。
- `public/`：网页静态资源、演示素材和浏览器模型资源。
- `electron/`、`android/`、`ios/`：桌面及移动端容器。
- `vocal_service/`：可选的私有评分服务。
- `tests/`：功能与浏览器测试。
- `docs/`：架构、部署、平台和验收文档。
